Vertical Chords (Press Top + Home, or Home + Bottom) Bridge seam with 1 finger pad 
 TOP + HOME — NUMBER-ROW SYMBOLS (Shift 1..8):
   Left:   Q+A → !    W+S → @    E+D → #    R+F → $    T+G → %
   Right:  Y+H → ^    U+J → +    I+K → *    O+L → &

 HOME + BOTTOM — OPERATORS & PUNCTUATION:
   Left:   S+X → `    D+C → \    F+V → =    G+B → ~
   Right:  H+N → _    J+M → -    K+, → /    L+. → |
Brackets & Angle Delimiters (Right Hand) Essential for C++ / Coding

   M + , → [  (Shift → { )              , + . → ]  (Shift → } )

 HOME ROW PARENTHESES:
   J + K → (  (Shift → < )              K + L → )  (Shift → > )
